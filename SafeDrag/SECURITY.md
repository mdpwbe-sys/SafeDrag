# Politique de sécurité

## Versions prises en charge

La branche de livraison 0.9.x reçoit les correctifs de sécurité pendant sa phase de préversion.

## Signaler une vulnérabilité

N'ouvrez pas de ticket public contenant une procédure d'exploitation, des données personnelles ou des chemins sensibles. Utilisez de préférence la fonction **Private vulnerability reporting** du dépôt GitHub. Si elle n'est pas disponible, ouvrez un ticket public sans détails exploitables afin de demander un canal privé.

Indiquez la version de SafeDrag, la version de Windows, le gestionnaire de fichiers concerné, le mode d'autorisation utilisé et une reproduction minimale.

## Périmètre

SafeDrag protège contre les dépôts accidentels effectués avec la souris. Les logiciels malveillants exécutés sous le même compte, les processus élevés, les opérations par API ou ligne de commande et les contrôles non exposés à UI Automation ne font pas partie de la frontière de sécurité garantie.
